# Mitwirken

Beiträge für nichtkommerzielle Zwecke sind willkommen.

1. Vor größeren Änderungen bitte zunächst ein Issue eröffnen.
2. Änderungen klein und thematisch fokussiert halten.
3. `npm run verify` vor einem Pull Request ausführen.
4. Neue Funktionen mit Tests und Dokumentation ergänzen.
5. Keine API-Schlüssel, Nutzbilder, Modelldateien oder generierten Artefakte committen.

Mit einem Beitrag erklärst du dich damit einverstanden, dass er unter der
Projektlizenz veröffentlicht wird. Kommerzielle Nutzung bleibt untersagt.
