# Mitwirken

Beiträge für nichtkommerzielle Zwecke sind willkommen.

1. Vor größeren Änderungen bitte zunächst ein Issue eröffnen.
2. Änderungen klein und thematisch fokussiert halten.
3. `npm run verify` vor einem Pull Request ausführen.
4. Neue Funktionen mit Tests und Dokumentation ergänzen.
5. Keine API-Schlüssel, Nutzbilder, Modelldateien oder generierten Artefakte committen.
6. Änderungen an IPC-Verträgen gleichzeitig in Main Process, Preload,
   Renderer-Typen und Tests aktualisieren.
7. Änderungen am 3MF-/STL-Export mit deterministischen Mesh-Tests absichern;
   insbesondere Wasserdichtigkeit, Materialzuordnung und Randfarben.

## Dokumentation

Bei sichtbaren Änderungen mindestens `README.md`, `CHANGELOG.md` und die
betroffene Datei unter `docs/` prüfen. Historische Changelog-Einträge bleiben
unverändert; entfernte Funktionen werden in einer neueren Version als entfernt
gekennzeichnet.

Mit einem Beitrag erklärst du dich damit einverstanden, dass er unter der
Projektlizenz veröffentlicht wird. Kommerzielle Nutzung bleibt untersagt.
